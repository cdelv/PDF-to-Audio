`voice.wav` and its exact `transcript.txt` are copied from the existing **Library Heavens Path** profile in `/opt/voicebox/data`. `prompt.txt` controls Qwen3's PDF cleanup. No voice or model was downloaded.

The app copies these defaults into `~/.local/share/pdf-to-audio/assets` on first launch. Settings lets you replace the sample and edit both text files. Use a clear 2–30 second WAV or FLAC recording and an exact transcript for voice cloning. The original Voicebox files are not modified.
